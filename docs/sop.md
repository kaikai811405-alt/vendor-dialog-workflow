# recapchat SOP — 廠商對話整理作業標準

## 摘要卡格式

```
---
👤 聯絡人：[姓名 / 公司]
📁 專案：[專案代號]
📌 任務：[任務名稱]
📅 日期：[對話日期]
📝 摘要：[2-3 句]
✅ Action Items：[條列]
🔩 SN 編號：[如有]
---
```

## ⚡ 已完成待辦確認格式（新增）

若本次資料證實現有 Notion Action Item 已完成，在摘要卡上方另列：

```
⚡ 已完成待辦確認：
- [ → ✅] [原待辦內容]（來源：本次信件/對話）
```

使用者確認後：打勾 checkbox + 在執行紀錄補記「完成時間：YYYY-MM-DD」。

## 任務寫入規則

### 寫入位置
- 所有任務（RMA / Bug / Event / Task）→ **專案任務清單**（`{專案}_任務清單`）
- 溝通記錄資料庫：**不使用**

### 類別對應
| 信件主旨關鍵字 | 類別 |
|----------------|------|
| RMA | 1_RMA |
| Bug / 不良 | 0_Bug |
| 一般討論 / 進度 | 2_Event |
| 設計變更 | 設變 |

### 範本選擇
- RMA → 使用 RMA 範本
- Bug → 使用 Bug 範本
- Task / Event → 使用 Task 範本

## 執行紀錄格式

每筆紀錄包含：
```markdown
## YYYY-MM-DD（上午/下午 — 信件/會議/Teams）
- **執行內容**：...
- **與廠商溝通**：...
- **決策/結論**：...
**待辦：**
- [ ] ...
```

## 異常處理

| 狀況 | 處理方式 |
|------|----------|
| 聯絡人無法比對 | 停下詢問，不自行猜測 |
| 無法判斷專案歸屬 | 停下詢問 |
| 比對到多個候選任務 | 列出選項讓使用者選 |
| 缺少日期 | 詢問使用者 |
| 電池/VDL等特殊任務無對應 | 詢問是否新建或歸入現有任務 |
